# Celestial Atlas

Create a premium, immersive astronomy and space exploration website that feels like it was designed by an award-winning digital product designer and built by an expert frontend engineer.

The website should NOT look childish, cartoonish, overly simplified, or like a generic school astronomy project. It should feel sophisticated, cinematic, scientific, modern, and visually impressive — somewhere between a professional space agency website, a high-end science publication, and an interactive digital observatory.

CORE THEME

The entire website should revolve around the beauty, scale, and mystery of the universe.

Use real astronomical imagery featuring things such as:

Planets

Moons

The Solar System

Galaxies

Nebulas

Star clusters

Supernovas

Black holes

Exoplanets

The Sun

Deep-space objects

Space missions

Astronauts

Space telescopes

Earth from space

IMPORTANT IMAGE REQUIREMENT

Use real astronomical imagery, not AI-generated illustrations, cartoons, clip-art, or generic stock space backgrounds.

Prioritize images from authoritative sources such as:

NASA

ESA

James Webb Space Telescope

Hubble Space Telescope

NASA/JPL

NASA Image and Video Library

ESA/Hubble

Other reputable scientific/astronomical institutions

Whenever possible, use the actual source image URL rather than replacing it with an artificial recreation.

Images should be high-resolution and visually striking.

For each major image, where practical, provide attribution/source information such as:

Image: NASA / ESA / CSA / STScI

Do not invent image credits.

If external images cannot be loaded directly during development, structure the image system so that the real NASA/ESA/etc. image URLs can easily be inserted later.

HOMEPAGE

Build a highly impressive homepage.

HERO SECTION

The hero should immediately establish the scale of the universe.

Use a full-screen or near-full-screen real astronomical photograph, preferably something visually spectacular such as:

A nebula

Galaxy

Deep-field image

Supernova remnant

Earth from space

Overlay the image carefully so text remains readable.

Example content:

THE UNIVERSE IS VAST.

And we're only beginning to understand it.

Then include a subtle call-to-action:

EXPLORE THE COSMOS →

Also include small scientific metadata such as:

13.8 BILLION YEARS
~93 BILLION LY OBSERVABLE UNIVERSE
TRILLIONS OF GALAXIES

Do not present uncertain scientific estimates as absolute facts. Where appropriate, include small explanatory notes.

The hero should have subtle motion:

Slow image movement/parallax

Very subtle star movement

Smooth text entrance

Scroll-driven transitions

Keep animations sophisticated and restrained.

SECTION: THE SOLAR SYSTEM

Create an immersive Solar System section.

Show the planets using real NASA imagery.

Do not simply make nine cards in a grid.

Instead, create an interactive or editorial experience where the user can explore planets.

Possible layout:

Sun → Mercury → Venus → Earth → Mars → Jupiter → Saturn → Uranus → Neptune

Each planet should include:

Name

Planet type

Diameter

Distance from Sun

Orbital period

Surface/atmosphere information

One or more fascinating facts

Use actual NASA imagery wherever possible.

The user should be able to click a planet and reveal more information.

Include subtle orbital visualization if appropriate.

Important:
Do not attempt to represent the planets to exact scale if doing so makes the interface unusable. Clearly distinguish between visual representation and scientific scale.

SECTION: DEEP SPACE

Create a major editorial section dedicated to deep-space objects.

Feature real astronomical photographs of:

Nebulas

Galaxies

Star clusters

Supernova remnants

Black holes

Cosmic structures

Make this feel like browsing a premium astronomy magazine.

Possible layout:

Large featured image on one side.

DEEP SPACE / 001

THE PILLARS OF CREATION

Then explain:

What the object is

Where it is located

Approximate distance

What telescope captured the image

Why astronomers study it

Create an editorial section explaining stellar explosions.

Use real astronomical imagery.

Explain:

How massive stars die

Type Ia vs core-collapse supernovae

How elements are produced

What remains afterward

Use visual storytelling rather than dumping large paragraphs of text.

OBSERVATION

SCIENTIFIC VISUALIZATION

If using the famous black-hole image, identify it correctly as an image produced by the Event Horizon Telescope collaboration.

SCIENTIFIC ACCURACY

This is extremely important.

The website should communicate real astronomy.

Do not invent:

Distances

Planet statistics

Discoveries

Mission information

Telescope observations

Scientific explanations

Use reliable sources such as NASA, ESA, JPL, STScI, and other reputable scientific institutions.

If a number is approximate, label it as approximate.

If something is a scientific visualization rather than a photograph, clearly identify it.

Build the site so images are:

Responsive

Lazy-loaded

Properly cropped

High resolution

Optimized where possible

Accessible with meaningful alt text

Use object-fit and responsive image sizing appropriately.

Do not distort astronomical images.

For galleries, allow the user to view images at larger sizes.

Include subtle captions and source information without visually overwhelming the photography.

The final result should feel like something that could realistically be presented as a professional astronomy platform, not a student template.

Imagine the design quality of:

NASA

ESA

National Geographic

premium editorial websites

modern scientific publications

but create an original visual identity rather than copying any one website.

Real astronomical photography > decorative graphics

Scientific credibility > fabricated content
